# Contributing

Keep changes focused on observable translation/lettering workflow problems. Use original synthetic fixtures instead of published manga pages. Do not upload font binaries, personal paths, credentials, source books, or translated books.

Run the unit tests, render the synthetic example with a local Urdu font, and inspect the resulting page when changing the renderer. Include source/expected behavior and reproduction steps in a bug report. Text fitting alone is not a visual quality check.

The skill should preserve explicit user scope. Keep default preferences separate from hard technical requirements, and do not add blanket approvals or unrelated workflows.

By contributing, you agree that your contribution is available under the repository's AGPL-3.0-or-later license.
